Dessiner Ensemble est un site participatif pour échanger entre dessinateurs débutants ou non sur les différentes techniques de dessin. 
L'utilisateur pourra consulter des articles sur les techniques illustrées avec des dessins, découvrir les œuvres de tous les participants dans une galerie et y ajouter ses propres réalisations et ses commentaires pour aider les autres à s'améliorer.
Les langages utilisés seront le HTML, le CSS, le SQL et le PHP avec le framework Symfony.
